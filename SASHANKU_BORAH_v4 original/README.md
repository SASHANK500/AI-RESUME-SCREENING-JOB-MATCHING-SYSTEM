# AI Resume Screening & Job Matching System v4

Professional Streamlit ATS-style screener with:
- polished recruiter dashboard
- batch candidate ranking
- stronger scoring
- per-candidate PDF report downloads

## Run

```bash
cd ats_resume_screener_v4
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
